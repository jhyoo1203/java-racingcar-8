# 🚗 자동차 경주

---

## 📌 기능 단위 구분

- [x] 자동차 등록
    - 쉼표(,)로 구분된 자동차 이름 입력 받기
- [x] 시도할 횟수 등록
    - 모든 자동차가 동일한 시도 횟수
    - 양의 정수만 입력 가능
- [x] 시도 횟수 만큼 모든 차량 전진 시도
    - 0~9 사이의 무작위 값 생성
    - 4 이상일 경우 전진, 3 이하일 경우 정지
- [x] 각 라운드별 실행 결과 출력
- [x] 우승자 판별
    - 가장 멀리 이동한 자동차 찾기
    - 공동 우승자 처리

---

## ⚠️ 검증

### 자동차
- [x] 적어도 두 대 이상의 차량 등록
- [x] 중복된 차량 이름 허용하지 않음
- [x] 영어와 숫자 형식만 허용
- [x] 자동차 이름은 최대 5글자
- [x] 빈 문자열 또는 공백만 있는 이름 불가

### 시도할 횟수
- [x] 숫자 형식 검증
- [x] 양의 정수만 허용 (0 이상)
- [x] 최대값 검증 (100 이하)

---

## ⭐️ 도메인 설계

### Car
- 이름(name): 자동차의 고유 이름
- 위치(position): 현재 이동 거리
- 전진 메서드
- 위치 getter
